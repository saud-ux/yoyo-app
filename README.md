# نبض — تطبيق تدريب واختبار التحمّل المتقطّع

تطبيق
`iOS`
أصلي مبني بـ
`React Native + Expo`.
لا يوجد
`WebView`
ولا أي طلب شبكة في التطبيق.

الاسم الحالي مؤقّت. غيّره من
`app.json`
(الحقول:
`name`
و
`slug`
و
`ios.bundleIdentifier`)
قبل أول رفع.

---

## الحالة: المرحلة الأولى مكتملة

المنجز حتى الآن هو العمود الفقري الصوتي فقط:

- مشروع
`Expo SDK 57`
بـ
`TypeScript strict`
و
`expo-router`.
- تهيئة جلسة صوت تعمل مع مفتاح الصامت وفي الخلفية.
- خمس نغمات مولّدة برمجيًا، بلا أي تسجيل خارجي.
- جدولة صوتية بالتوقيت المطلق بدل التوقيت المتسلسل.
- شاشة "مختبر الصوت" لقياس ذلك على جهاز حقيقي.

لم تُبنَ بعد: محرّك البروتوكول، الشاشات، التخزين، الخطة، المؤقّت.

## الأوامر

```bash
npm install          # تثبيت الاعتماديات
npm start            # تشغيل خادم التطوير
npm run typecheck    # فحص الأنواع
npm run tones        # إعادة توليد ملفات الصوت
```

## بنية المشروع

```
app/                 شاشات expo-router
  _layout.tsx        الجذر: تحميل النغمات
  index.tsx          مختبر الصوت
src/audio/
  session.ts         تهيئة جلسة الصوت (الصامت + الخلفية)
  cues.ts            مشغّلات النغمات + الاهتزاز
  keepAlive.ts       الحلقة الصامتة التي تبقي التطبيق حيًّا
src/timing/
  cueSchedule.ts     جدولة بالتوقيت المطلق مع قياس الانحراف
scripts/
  generate-tones.mjs مولّد ملفات الصوت
assets/audio/        النغمات المولّدة (مولّدة، لا تُعدَّل يدويًا)
```

## كيف يبقى الصوت شغّالًا والشاشة مقفلة

ثلاث قطع مطلوبة معًا، وغياب أي واحدة يُسقط الاختبار كله:

1. `UIBackgroundModes: ["audio"]`
   في
   `app.json`
   — يمنح التطبيق حق تشغيل الصوت في الخلفية.

2. `playsInSilentMode: true`
   و
   `shouldPlayInBackground: true`
   في
   `src/audio/session.ts`
   — تتجاوز مفتاح الصامت وتُبقي الجلسة نشطة.

3. حلقة صامتة مستمرة في
   `src/audio/keepAlive.ts`
   — نظام
   `iOS`
   يوقف التطبيق في الخلفية إن لم يكن هناك صوت فعلي يخرج منه. بين شوطين توجد
   عشر ثوانٍ صمت، وهي كافية لتعليق التطبيق وإيقاف كل المؤقّتات. الحلقة تُشغّل
   ملفًا بشدّة صوت مقدارها وحدة واحدة من 32767 — غير مسموعة إطلاقًا — فتبقى
   الجلسة نشطة والمؤقّتات تعمل.

## النغمات

كلها مولّدة من جدول ترددات في
`scripts/generate-tones.mjs`،
ولا يوجد أي تسجيل رسمي محمي بحقوق نشر في المشروع.

| الملف | الوصف | المدة |
|---|---|---|
| `beep.wav` | 880 هرتز — بداية ونهاية الشوط | 150 م.ث |
| `level.wav` | 1320 هرتز مزدوجة — مستوى جديد | 390 م.ث |
| `tick.wav` | 660 هرتز — عدّ 3-2-1 | 110 م.ث |
| `end.wav` | نغمة هابطة 1200←400 — نهاية الاختبار | 1000 م.ث |
| `silence.wav` | حلقة غير مسموعة لإبقاء الجلسة نشطة | 1000 م.ث |

كل نغمة تحتوي على الأساس مع توافقيتين
(`PARTIALS`
في المولّد)
لأن سمّاعة الجوال ضعيفة عند الترددات المنخفضة، والهدف أن تُسمع على بعد 20 مترًا
في الهواء الطلق. الطبقة المسموعة تبقى هي التردد الأساسي المذكور. لنغمة جيبية
نقية تمامًا، اجعل
`PARTIALS`
عنصرًا واحدًا فقط وأعد تشغيل
`npm run tones`.
