# برنامج اليو‑يو — Yo‑Yo IR1 Trainer

موقع صفحة واحدة (HTML / CSS / JavaScript، بدون أي أدوات بناء) يعرض برنامج تدريب **٨ أسابيع** لاجتياز اختبار
`Yo-Yo Intermittent Recovery Test — Level 1`
على شكل **تمارين مهيكلة** جاهزة للإدخال في
`Garmin Connect`
وتُقاد بالاهتزاز على ساعة
`Vivoactive 5`.

## التشغيل
افتح `index.html` في المتصفّح مباشرة — الملف مستقلّ بذاته. كتطبيق `PWA` يُقدَّم عبر خادم `HTTPS` (مثل `Netlify`) ليُثبَّت ويعمل دون إنترنت.

## المزايا
- **٤٥ تمرينًا** موزّعة على ٨ أسابيع (تأسيس ← بناء ← استشفاء ← تخفيف)، منها ١١ جلسة تقوية وقائية.
- **نطاقات نبض تفاعلية** بطريقة `Karvonen`؛ عدّل العمر/نبض الراحة/النبض الأقصى المُقاس فتتحدّث كل أهداف التمارين تلقائيًا.
- **موعد اختبار قابل للتعديل** يحرّك العدّاد التنازلي ويوم الاختبار.
- **جدول بتواريخ حقيقية**: بداية البرنامج تُشتقّ تلقائيًا من موعد الاختبار (أحد الأسبوع الذي يقع فيه، ناقص ٧ أسابيع) فيصير لكل يوم تدريب تاريخ فعلي، ويُبرز يوم اليوم، ويُختار أسبوعك الحالي تلقائيًا مع وسم «هذا الأسبوع» و«الأسبوع الجاي».
- **تأجيل مرن على مستويين**:
  - *البرنامج كله* — «أجّل أسبوع / أجّل يوم / قدّم يوم» يزيح الجدول بالكامل، مع تنبيه صريح إن صار يوم الاختبار يقع قبل الأسبوع الثامن (أي لن تُكمل البرنامج قبله).
  - *تمرين واحد* — زر «أجّله» على البطاقة، أو «ما أتمرّن اليوم» الذي يؤجّل تمارين تاريخ اليوم دفعةً واحدة. المؤجَّل يُعرض باهتًا ويُجمَّع في شريط «مؤجّلة»، ومنه ترجعه لموعده الأصلي أو **تنقله لتاريخ تختاره** فيتبعه الجدول والتقويم المُصدَّر.
- **سجلّ نتائج الاختبارات الثلاثة**: أدخِل المسافة بعد كل اختبار فيُحسب تقدير
  `VO2max`
  بمعادلة
  `Bangsbo`
  (المسافة × ٠٫٠٠٨٤ + ٣٦٫٤)، ويُعرض الفرق بالمتر والنسبة بين اختبار وآخر. المشغّل نفسه يعرض زر «احفظ المسافة» عند التوقّف فيكتبها في الاختبار الصحيح مباشرة.
- **معايرة النبض الأقصى** من أعلى نبض سجّلته الساعة في الاختبار — بضغطة واحدة يستبدل تقدير
  `Tanaka`
  ويعيد حساب كل النطاقات وسكربت الـ
  `FIT`.
- **تقوية وقائية** (نورديك للأوتار الخلفية، رفع سمانة، بلانك جانبي) مرّتين أسبوعيًا على اليومين الشديدين، بجرعة أقل في أسبوع الاستشفاء ولا شيء في أسبوع التخفيف.
- **تقييم الجهد** `RPE` ١–١٠ بعد كل تمرين، مع تنبيهات تلقائية: حِمل مرتفع متواصل، تأجيلات متراكمة، واستشارة تخفيف الأسبوع الثامن مبنيّة على ما أُنجز فعلًا في أسابيع ٥–٧.
- **نسخة احتياطية** `JSON` للتصدير والاستيراد — التقدّم كلّه محفوظ في متصفّح واحد، والنسخة تحميه من تنظيف البيانات أو تبديل الجهاز.
- **تصدير التقويم** بملف `.ics` قياسي (RFC 5545) لكل التمارين بتواريخها الفعلية، جاهز للاستيراد في تقويم الجوال.
- **مشغّل صافرات `YYIR1` بالتسجيل الصوتي الرسمي** (`audio/yoyo.mp3`): تُشغّل الصوت الحقيقي وتتزامن الشاشة معه لعرض المستوى والسرعة والمسافة لحظيًا. الجدول الزمني (بدايات المستويات والسرعات) مستخرَج من تحليل الصوت عند تردد الصافرة ١٠٠٠ هرتز.
- **شرح لكل تمرين** عبر زر «!» في زاوية البطاقة: خطوات التنفيذ في الملعب، معنى الاهتزاز، الشدّة، والخطأ الشائع.
- **تطبيق `PWA`** قابل للتثبيت يعمل دون إنترنت. الصوت (≈٢٨ ميجا) لا يُحمَّل مع التثبيت بل بزر صريح مع شريط تقدّم، والـ `service worker` يخدم طلبات `Range` بتقطيع النسخة المخزّنة (الـ `Cache API` يرفض تخزين استجابات `206`، وهذا سبب فشل التشغيل دون إنترنت سابقًا).
- بطاقة لكل تمرين بصيغة خطوات `Garmin` الدقيقة، مع زر **نسخ الخطوات** وعلامة **إنجاز** تُحفظ في المتصفّح.
- **سكربت `FIT` مُولَّد آليًا** من بيانات البرنامج ونطاقاتك الحالية — يغطّي الـ ٤٥ تمرينًا كلها (نسخ أو تنزيل كملف)، ويتحدّث فور تعديل أي رقم من أرقامك.
- سمة فاتحة/داكنة، وتصميم يمين‑لليسار.

## جدول الصوت المستخرَج (السرعات وبدايات المستويات)
التسجيل ≈٢٧ دقيقة. أول صافرة ≈٢٩ث، وأول جولة محتسبة ≈٤٠٫٦ث. الاستشفاء ≈٥ث. الجولة = ٢×٢٠م.
السرعات (km/h): 11.5 → 12.5 → 13.5 → 14.0 → 14.5 → 15.0 → 15.5 → 16.0 → 16.5 → 17.0 → 17.5 → 18.0. المسافة القصوى ≈٤٤٨٠م.
